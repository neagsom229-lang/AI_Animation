# START HERE — Khmer Empire illustrated film

Five commands. Copy/paste in order from the repository root.

```bash
# 1. One Python environment (creates/repairs .venv-depth; verifies all imports)
node scripts/film.mjs setup

# 2. One drop folder: put your images in assets-src/inbox/scene-NN.png, then ingest
node scripts/film.mjs ingest

# 3. Depth maps for the 2.5D parallax (depth-based camera movement, not true 3D)
node scripts/film.mjs depth

# 4. Exactly ONE next action + the blocker count (no guessing)
node scripts/film.mjs next

# 5. Render a draft (720p) and watch it — the file says DRAFT - NOT RELEASABLE
node scripts/film.mjs render
```

## Before you go further

- **One env:** `.venv-depth` (Python + torch/transformers/Pillow/numpy/edge-tts).
  The old `.venv` is deprecated and only warns.
- **One drop folder:** `assets-src/inbox/`. Keep an original copy elsewhere;
  ingest copies into timestamped `assets-src/backup/<ts>/` and never overwrites
  your source files.
- **Profiles:** draft is the default for ingest/depth/render. A draft downgrades
  low resolution, duplicates, aspect crops and a missing licence URL to warnings.
  `--profile final` has **no `--force`** — it keeps every block.
- **Review:** open `out/review/review.html` (built with
  `node scripts/film.mjs review sheet`), then record ONE scene at a time:
  `node scripts/film.mjs review --scene N --matches-narration yes --watermark clear --reviewed yes`
  and `node scripts/film.mjs review --license-url <tool's licence URL>`.
  Nothing sets `reviewed`, `matchesNarration`, `watermarkCheck` or
  `licenseTermsUrl` automatically.
- **STATUS.md:** generated by `node scripts/film.mjs status`; do not edit by hand.
  It joins the manifest, parallax metrics and last render times in one table.
- **A draft is never releasable.** The final profile keeps duplicates, small
  sources, unreviewed scenes and an empty licence URL as hard blocks.
